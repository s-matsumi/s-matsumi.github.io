プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-25

1. 取得するデータ / Data accessed

Hermes Personal Assistant は、所有者本人の Google アカウントについて、所有者が許可した範囲で以下のデータにアクセスします。

  • Gmail：メールの閲覧、ラベル変更、送信 / Gmail: read, modify labels, send
  • Google カレンダー：予定の閲覧・作成・削除 / Google Calendar: read, create, delete events
  • Google コンタクト：読み取りのみ / Google Contacts: read-only

2. 利用目的 / How data is used

取得したデータは、所有者本人の指示に基づくメール整理・予定管理などのアシスタント機能を提供する目的にのみ使用します。広告、販売、プロファイリング、AI モデルの学習には使用しません。

Data is used solely to perform assistant tasks requested by the owner. It is never used for advertising, sold, used for profiling, or used to train AI models.

3. 保存 / Storage

OAuth トークンは所有者のパソコン上にのみ保存されます。メールや予定のデータは処理に必要な間だけ扱い、外部のサーバーに保管しません。

OAuth tokens are stored only on the owner's own computer. Email and calendar data are processed only as needed and are not stored on external servers.

4. 第三者提供 / Sharing

取得したデータを第三者に販売・提供することはありません。

Data is not sold or shared with third parties.

5. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

本アプリによる Google API から取得した情報の使用および他アプリへの転送は、限定使用の要件を含む Google API Services User Data Policy に準拠します。

Hermes Personal Assistant's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセスの取り消し / Revoking access

所有者は Google アカウントの権限設定 からいつでもアクセスを取り消せます。

Access can be revoked at any time from Google Account permissions.
